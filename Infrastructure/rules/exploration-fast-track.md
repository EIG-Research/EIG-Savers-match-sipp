# Exploration Fast-Track

**Lightweight workflow for experimental work.** Suggested threshold: 60/100 for exploration quality (production remains stricter).

## Steps

1. **Research value check** -- does this exploration help answer the project question?
2. **Create folder** -- `mkdir -p Infrastructure/explorations/[name]/{code,notes,output}` + `README.md` + `SESSION_LOG.md`.
3. **Code quickly** -- require runnable code, correct results, and clear goal; defer polish.
4. **Log progress** -- append 2-3 lines to `SESSION_LOG.md` as you work.
5. **Decision point** -- continue exploring, graduate to production, or archive.

## When to Stop (Kill Switch)

If value is low or blockers dominate, stop, archive with a short note, and move on.
