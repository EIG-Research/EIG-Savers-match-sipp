# Literature Reference Store

This folder is the canonical store for papers, data dictionaries, codebooks, and agent summaries that should be reusable across sessions.

## Structure

- `catalog.yaml`: machine-readable index used by agents for discovery
- `papers/`: saved research papers and technical notes
- `data_dictionaries/`: schema docs, codebooks, data dictionaries
- `summaries/`: extraction notes and concise summaries generated by agents

## Operating Rule

When adding literature, always follow `Infrastructure/commands/literature-intake.md` so the catalog stays complete and searchable.

## Validation

Run `python3 Infrastructure/scripts/validate_literature_catalog.py` after catalog updates to verify required fields, ID uniqueness, and path validity.
