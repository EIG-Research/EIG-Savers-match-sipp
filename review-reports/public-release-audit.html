2 · MUST add — missing standard files

Three files that any public repository should have are entirely absent.
A-001 LICENSE — missing entirely MUST

Why it matters: Without a license, the default under copyright law is "all rights reserved." An outside researcher cannot legally run, modify, or redistribute the code. This is a public release blocker.

Recommendation: For a research codebase, MIT License is the most common choice (permissive, allows reuse). If EIG wants to ensure attribution, consider Apache 2.0. If the intent is purely to enable replication, CC0 (public domain dedication) is also appropriate.

Action: Create LICENSE in the repo root. GitHub's "Add file → Create new file → name it LICENSE" will offer license templates.

A-002 .gitignore — missing entirely MUST

Why it matters: The README explicitly says pu2024.dta is "listed in .gitignore" — but no .gitignore exists. If someone clones and runs the pipeline, generated intermediates (the ~2GB DTA file, the expanded CSV, R session files) risk being accidentally committed.

Recommended .gitignore content:

A-003 CITATION.cff — missing entirely MUST

Why it matters: GitHub renders CITATION.cff as a "Cite this repository" button. Without it, researchers have no machine-readable way to attribute the code. Given that this is a replication repository for a policy paper, citation metadata is important.

Recommended minimal CITATION.cff:
