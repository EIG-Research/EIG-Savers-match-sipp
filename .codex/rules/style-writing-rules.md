# Style Writing Rules

Binding rules for EIG prose style.

## Canonical Sources

- `Infrastructure/style/docs/eig-writing-style.md`
- `Infrastructure/style/docs/eig-document-process.md`

## Core Rules

1. Use `percent` in body text; reserve `%` for chart labels.
2. Spell out one through nine; use numerals for 10 and above.
3. Use Oxford commas in lists of three or more.
4. Use active voice where feasible.
5. Avoid contractions in formal outputs.
6. Keep terminology stable (avoid elegant variation for core concepts).
7. Use one-sentence ledes for briefs/blog-style outputs.
8. Include `Why it matters` framing early.

## Common Error Triggers

- `US` (without periods) used adjectivally instead of `U.S.`
- `COVID19` or `Covid-19` instead of `COVID-19`
- `home ownership` instead of `homeownership`
