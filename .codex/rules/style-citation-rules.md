# Style Citation Rules

Binding rules for EIG citations.

## Canonical Source

- `Infrastructure/style/docs/eig-citation-style.md`

## Requirements

1. Every citation ends with a period.
2. Year is not parenthesized in EIG citation format unless explicitly required by output style.
3. Article/post titles are in quotation marks.
4. Book/report titles are italicized in markdown (`*title*`).
5. Use `et al.` for four or more authors.
6. Include access date for webpages when available.
7. Do not use `Retrieved from`.
